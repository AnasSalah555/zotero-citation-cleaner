## 📌 Description
A Python script designed to automatically remove hidden Zotero/Mendeley duplicate citations from Word (`.docx`) documents by matching DOIs or titles, unifying their hidden URIs and IDs, and cleaning the XML structure without corrupting the file.

---

## 🚀 How to Use (Google Colab)
1. Open [Google Colab](https://colab.research.google.com/).
2. Paste the provided script into a new notebook cell.
3. Run the cell and upload your Word document (`.docx`) when prompted.
4. Download the cleaned file (`Manuscript_Deduplicated_Clean.docx`).
5. Open the file in Microsoft Word (make sure Zotero is open) and click **Refresh** on the Zotero ribbon.
